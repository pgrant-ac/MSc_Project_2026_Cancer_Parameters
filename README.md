# MSc_Project_2026_Cancer_Parameters
Collection of code used for my MSc Data Science for Biology dissertation project entitled: "Studying Gene Activity Patterns in Cancer Cells Treated with Immunotherapy".

Different parts of the project are saved in different folders:

* **NB_Methods:** Tests on different methods of estimating negative binomial (NB) parameters from simulated count data in R to choose the most robust method.
* **Simulations:** Simulating count data and using the chosen method of estimation to determine errors on both perfect and corrupted count data.

The RNAseq data was obtained from the researcher's GitHub found here:  
[https://github.com/MahnoorNGondal/scRNA-seq-ICB-cohorts](https://github.com/MahnoorNGondal/scRNA-seq-ICB-cohorts)
